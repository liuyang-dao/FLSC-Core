这不是技术规范，是一份**认知元理论**。

三者全是结构映射（真跳跃），详见 `logs/great_intuitions_flsc_reading.md`。

> *"万象入脑皆编码，五元为锚自昭昭。*

## 使用说明

1. **想理解 FLSC 全貌** → 从 `spine/index.md` 开始
2. **想接入自己领域** → 读 `domains/README.md` 的接入规范
3. **想给 AI 加载脊线** → 直接 `import yaml` 加载任意 `.yaml` 文件
4. **想理解"直觉"的底层逻辑** → 读 `domains/cognition/`
